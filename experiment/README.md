# Experiments

Các thực nghiệm được thực hiện trên 3 bộ dữ liệu, bao gồm các mô hình baseline và mô hình đề xuất để đánh giá hiệu quả của phương pháp.

## Cấu trúc thư mục

```
.
├── notebooks/        # Các notebook để thực nghiệm
└── checkpoints/      # Checkpoint của 3 dataset
```

## Chỉ số

`MAE`, `MSE` (hồi quy điểm), `Accuracy`, `Precision`, `Recall`, `F1` (phân loại match, ngưỡng 0.5).
